# 重要提示 / Important Notice

本工具会修改 Windows 的设备记录与 COM 端口占用表。
所有改动都会先做留底（C:\ProgramData\ComFix\backup），可通过「还原上次」退回。
请在生产环境使用前，先在单台机器上验证。

This tool modifies Windows device records and the COM port arbiter table.
Every change is snapshotted first (C:\ProgramData\ComFix\backup) and can be
rolled back via "Restore last". Validate on a single machine before rolling
out to production.
